# BtoB 电商客服

按企业知识库回答采购方企业的咨询。本 glossary 只定义领域用语，不含 DSL 实现细节。

## Language

**客户**：
采购方企业本身。业务对象是公司，不是聊天窗口里打字的那个人。
_Avoid_: 买家（C 端含义）、消费者、询价字段抽取里的「客户名称」

**对接人**：
代表客户发消息的人。不单独作为业务对象建模。
_Avoid_: 客户（不要把个人叫成客户）

**BtoB电商知识**：
工作区中名为「BtoB电商知识」的企业资料，是客服答复的唯一事实来源。
_Avoid_: 模型常识、公开互联网、对话记忆（记忆只用于指代，不是事实来源）

**客服答复**：
只陈述 BtoB电商知识中已有的内容。不报价、不接单、不改订单。即使知识里写着单价，也不读出该数字，只转述询价路径。
_Avoid_: 报价、下单、改单、代商务做承诺、把价目表读给对接人

**交易引导**：
知识库中关于如何走询价、下单、账期、售后等流程的说明。客服可以转述这些说明，但不代替执行交易。
_Avoid_: 客服直接报价或下单

**未找到相关资料**：
当前检索到的 BtoB电商知识撑不起本问。此时礼貌致歉并请对接人补充信息；话术不必每次相同；不提转人工。
_Avoid_: 对对接人说「资料不足」「无法为您提供」「无法准确回答」「知识库没有」；转人工；用模型常识补全

**部分答复**：
一问多事时，参考资料能支撑的部分照常回答，撑不起的部分单独致歉并请补充。
_Avoid_: 整句放弃；对撑不起的部分保持沉默；说「无法提供」

**称呼**：
开场问候、致歉、郑重说明时可用「尊敬的客户」（非中文用 Dear customer）。同一段回复里后续短句用「您」/ you，不要句句重复全称。
_Avoid_: 贵司；规定只能开场用一次；向对接人索要公司名后再改称呼

**答复语种**：
对接人当前这句用什么语言，客服就用什么语言答。英文问英文答，日文问日文答，其他外语同理。知识原文是中文时，只把同一事实译成该语种，不另加内容。
_Avoid_: 一律中文；因知识库是中文就改用中文回复；把外语问题先译成中文再答

**事实来源优先级**：
本轮 BtoB电商知识与硬规则（不报价、不接单、不改订单）高于对话记忆。记忆只用于解析指代，不把记忆里出现过的价格或承诺当成可再引用的事实。
_Avoid_: 用上轮答复当价目表；本轮没召回就沿用记忆中的条款
