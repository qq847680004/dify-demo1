# 报价推荐

根据询价单基础字段生成报价草案，供询价工作台「AI 报价推荐引擎」页展示。本应用不拥有询价单，不写报价单。

询价工作台用语：**询价单 / 报价草案 / 费用行 / 召回线索 / 运输方式 / 货品规格 / 补充信息 / 起运港名称 / 目的港名称**。AI 数据用语：**有效运价 / 相似历史单 / 费用项 / 进出口 / 运价类型 / 货运类型 / 检索句 / 规格价 / 费用种类 / 涨跌对照 / 市场运价涨跌**。

## Language

**运输方式**：
询价必填的大类（空运 / 海运 / 铁运 / 汽运 / 多式联运）。
_Avoid_: 用运输方式当有效运价主表名

**运价类型**：
有效运价的一张主表。海运下的整箱 / 拼箱 / 特种 / 冷冻 / FBA 等是运价类型，不是「还召不召回有效运价」的开关。
_Avoid_: 把整箱当成有效运价模块开关

**有效运价召回**：
仅当能选出已有运价类型时调用有效运价接口。没有对应主表（空运进口、汽运、多式联运）则不调，提示去补运价。
_Avoid_: 规格或整箱未写出就不走运价节点

**起运港名称 / 目的港名称**：
询价与 Agent JSON 的 `originPortName` / `destPortName`（工作流入参 `origin_port_name` / `dest_port_name`）。无港码或该运价表无代码列时作精确过滤。
_Avoid_: `originPlace` / `destPlace`；把港名和港码同时 AND

**货运类型**：
订单检索的 `bizType`（如 `SEA_EXPORT` / `AIR_IMPORT` / `TRUCK_EXPORT` / `RAIL_EXPORT` / `INTERMODAL`）。
_Avoid_: 把运价类型 `FCL_EXPORT` 写进订单 Body
