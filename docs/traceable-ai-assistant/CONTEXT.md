# 可溯源 AI 智助箱

面向内部业务员，按公司运价库、港口名录、货关分类与历史案例库（含 SOP）作答，答复可溯源到原始文档。本 glossary 只定义领域用语，不含 DSL 实现细节。

## Language

**业务员**：
使用本助手的内部销售/操作人员。不是采购客户，也不是询价抽取里的「客户名称」。
_Avoid_: 客户、对接人（BtoB 电商客服含义）、消费者

**运价库**：
公司航线运价资料。上下文中出现的运价与条件可以读给业务员；未出现的数字不得补全。
_Avoid_: 模型常识补价；把上轮对话里的运价当本轮价目表

**港口名录**：
港口中英文名、代码及对照资料。
_Avoid_: 未出现在检索结果中的港口码互转

**货关分类**：
货物与海关/HS 分类资料。
_Avoid_: 凭货名臆造 HS 码

**历史案例库**：
历史操作案例与 SOP 指引文档。导入时若 SOP 独立成库，视为同一事实来源族的另一库。
_Avoid_: 编造未检索到的处理步骤

**可溯源答复**：
结论、数字、条款须能对应本轮检索上下文中的文档，并点出文档名、航线或条款出处。Web 端同时展示知识引用来源。
_Avoid_: 无出处的运价与承诺；把记忆当文档

**未找到相关资料**：
本轮检索撑不起该问。致歉并请业务员补航线、港口、箱型、货名等。
_Avoid_: 对业务员说「知识库没有」「无法提供」「资料不足」

**转人工专属运价专家**：
运价查不到、拿不准，或业务员要专属/议价运价时，提示可转人工专属运价专家。这是唯一允许提出的人工路径。
_Avoid_: 编造其他岗位、电话、工号；把转人工当成默认每句结尾

**部分答复**：
一问多事时，上下文能支撑的照常答并带来源；撑不起的部分单独致歉并请补充。
_Avoid_: 整句放弃；对撑不起的部分用常识补全

**事实来源优先级**：
本轮检索资料高于对话记忆。记忆只用于解析「那条航线」「上次那个港」等指代；本轮未召回不得沿用上轮数字。
_Avoid_: 用上轮答复当运价表
