## Agent skills

### Issue tracker

Issues 与 specs 存放在本仓库 `.scratch/<feature-slug>/` 下的 markdown 文件中。See `docs/agents/issue-tracker.md`.

### Triage labels

使用默认 triage 词汇：`needs-triage`、`needs-info`、`ready-for-agent`、`ready-for-human`、`wontfix`。See `docs/agents/triage-labels.md`.

### Domain docs

Single-context：根目录 `CONTEXT.md` + `docs/adr/`。See `docs/agents/domain.md`.
